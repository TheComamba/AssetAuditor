# Version 2.1.0

A huge thank you to [vertigoogle](https://github.com/vertigoogle), who contributed almost all of the improvements in this release. Their work has substantially modernized and expanded Asset Auditor, and it is very much appreciated!

## New features

- Asset usages are now grouped by their saved file path.
- Asset usages can be shown and searched by their parent document.
- Original documents can be opened directly from the audit results.
- Wildcard patterns now show how many paths they match, and a warning is shown before replacing them.
- The audit now shows staged progress and explicit scan outcomes.

## Improvements

- The audit window has been modernized using ApplicationV2 and now has a responsive layout.
- Search and filters reuse audit snapshots, making them faster.
- Local asset paths are compared consistently across browser platforms.
- The audit workflows are now documented in the README.

## Bug fixes

- Fixed validation of Core Data asset paths.
- Fixed autosaving through the file picker; repaired asset paths are now revalidated.
- Embedded asset identities are preserved, and prototype token paths are persisted correctly.

## Maintenance

- Added cross-platform module validation.
- Switched to npm and updated dependencies.
